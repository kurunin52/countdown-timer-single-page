# Countdown Timer - Single Page

このリポジトリは、指定したカウント（デフォルト 60）を指定秒ごとにカウントダウンする、非常にシンプルな single-page アプリです。

特徴:
- 1ファイルの UI (index.html) + styles.css
- カウントダウンの実行処理は Hyperscript (https://hyperscript.org/) で実装
- 開始カウントと間隔（秒）を指定可能
- Start / Stop / Reset ボタン

使い方:
1. リポジトリをクローンするか、GitHub Pages にデプロイします。
2. index.html をブラウザで開くと動作します。

GitHub Pages:
- リポジトリの Settings > Pages から main ブランチの / (root) を選択すると公開できます。
