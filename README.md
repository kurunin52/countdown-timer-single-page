# Countdown Timer - Single Page

このリポジトリは、指定したカウント（デフォルト 60）を、指定した合計秒数をかけてカウントダウンするシンプルな single-page アプリです。

変更点:
- 「開始カウント」入力はデフォルトで折りたたまれて隠されています（必要に応じて設定を開いて変更できます）。
- ユーザーが指定するのは「合計経過秒数」です。例えば「65」と入力すると、60 カウントを 65 秒かけてカウントダウンします（各カウントの間隔は自動計算されます）。

特徴:
- Hyperscript による実行処理
- Start / Stop / Reset

使い方:
1. リポジトリをクローンまたは GitHub Pages で公開して index.html をブラウザで開きます。
2. 右上の「設定を表示」をクリックして（必要なら）開始カウントを変更します。
3. 合計経過秒数を入力して Start を押すと、指定した秒数でカウントダウンします。
